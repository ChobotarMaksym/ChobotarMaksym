### 📊 Featured Analytics Projects

#### 1. [Speed Dating Match Mechanics: Popularity vs. Compatibility](https://github.com/ChobotarMaksym/speed-dating-mutual-choice)
* **Domain:** Social Discovery / Recommender Ranking
* **Core Question:** Should a matching algorithm optimize for pair-level compatibility or candidate response propensity?
* **Approach:** Evaluated ranking logic on 8.3k dates using binomial GLMs and grouped CV.
* **Finding:** Pair compatibility features failed to provide an out-of-sample lift, while candidate reply propensity yielded a **+0.067 per-user AUC gain**. Debunked the selectivity paradox by demonstrating that match drop-off is driven by popularity ($\beta \approx 5.0, p < 0.001$).
* **Stack:** Python (pandas, statsmodels, scikit-learn, SciPy)

#### 2. [E-commerce Funnel Analysis (GA4)](https://github.com/ChobotarMaksym/ga4-ecommerce-funnel-tableau)
* **Domain:** E-commerce / Conversion Optimization
* **Core Question:** Where do drop-offs occur across the user journey, and do device types drive discrepancies?
* **Approach:** Processed 350K+ sessions from Google Analytics 4 sample dataset via BigQuery SQL into an interactive Tableau dashboard.
* **Finding:** Identified that ~80% of total drop-offs happen before reaching product pages, proving that top-of-funnel acquisition quality is a higher leverage lever than checkout-stage optimizations.
* **Stack:** BigQuery SQL, Tableau, Funnel & Cohort Analysis
